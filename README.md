# Crafting Interpreters Chapter Answers

This repository contains my answers to the exercises and questions from *Crafting Interpreters*. I organize the work by chapter, with each chapter or group of chapters in its own folder.

For implementation exercises that build on earlier work, I copy the relevant files from the previous chapter folder into the new chapter folder, regardless of the programming language or implementation type. I make chapter-specific changes only in the new folder, so earlier versions stay available as a reference and are not overwritten.
